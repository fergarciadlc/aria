# ARIA Dataset Generation Scripts

This folder contains scripts for generating the ARIA dataset in three stages:

## Pipeline Overview

```
MoisesDB → [1. Prepare] → Real Stems → [2. Generate AI] → AI Stems → [3. Generate Mixes] → Final Dataset
```

---

## 1. Prepare MoisesDB (`prepare_moisesdb.py`)

Extracts and organizes real stems from the MoisesDB dataset.

**Output structure:**
```
{track_id}/
├── metadata.json
└── stems/
    └── real/
        ├── vocals.wav
        ├── drums.wav
        ├── bass.wav
        └── other.wav
```

**Usage:**
```bash
python prepare_moisesdb.py
```

---

## 2. Generate AI Stems (`generate_ai_stems.py`)

Processes real stems through audio codecs (Encodec) to create AI-reconstructed versions.

**Output structure:**
```
{track_id}/
└── stems/
    ├── real/              # From step 1
    │   └── ...
    └── ai_generated/      # NEW
        └── encodec_3/
            ├── vocals.wav
            ├── drums.wav
            ├── bass.wav
            └── other.wav
```

**Usage:**
```bash
# Process all tracks with encodec at 3kbps
python generate_ai_stems.py

# Process first 10 tracks (testing)
python generate_ai_stems.py --limit 10

# Process with multiple bandwidths
python generate_ai_stems.py --bandwidths 3 6 24
```

**Codec Options:**
- `encodec_3`: Encodec at 3 kbps (most degraded, default)
- `encodec_6`: Encodec at 6 kbps (medium)
- `encodec_24`: Encodec at 24 kbps (higher quality)

---

## 3. Generate Mixes (`generate_mixes.py`)

Creates all possible combinations of real and AI-generated stems (2^n mixes per track), including the all-real reference mix (U0).

**Output structure:**
```
{track_id}/
└── mix/
    ├── U0/                # 0 AI stems (all real)
    │   ├── mix_S-empty.wav
    │   └── mix_S-empty.json
    ├── U1/                # 1 AI stem
    │   ├── mix_S-0.wav
    │   ├── mix_S-0.json
    │   ├── mix_S-1.wav
    │   ├── mix_S-1.json
    │   └── ...
    ├── U2/                # 2 AI stems
    │   ├── mix_S-0-1.wav
    │   ├── mix_S-0-1.json
    │   └── ...
    └── U4/                # All AI stems
        ├── mix_S-0-1-2-3.wav
        └── mix_S-0-1-2-3.json
```

**Usage:**
```bash
# Generate all mixes with default codec (encodec_3)
python generate_mixes.py

# Process first 10 tracks (testing)
python generate_mixes.py --limit 10

# Use different codec
python generate_mixes.py --codec encodec_6

# Force regeneration of existing mixes
python generate_mixes.py --force
```

**Mix Metadata:**
Each mix includes a JSON file with:
- `mix_name`: Mix identifier (e.g., "mix_S-0-2")
- `num_stems`: Total number of stems in the track
- `num_ai_stems`: Number of AI-generated stems in this mix
- `ai_stem_indices`: List of which stem indices are AI-generated (0-indexed)
- `ai_codec`: Which codec was used (e.g., "encodec_3")
- `stem_names`: Names of the stems (e.g., ["vocals", "drums", "bass", "other"])

**Example metadata:**
```json
{
  "mix_name": "mix_S-0-2",
  "num_stems": 4,
  "num_ai_stems": 2,
  "ai_stem_indices": [0, 2],
  "ai_codec": "encodec_3",
  "stem_names": ["vocals", "drums", "bass", "other"]
}
```

**Design Note:**  
All mixes (including U0/all-real) are generated by this script for consistency. This ensures:
- Uniform mixing algorithm across all mixes
- Complete metadata for all mixes (including U0)
- Separation of concerns (stem extraction vs. mixing)
- Flexibility to regenerate mixes without re-extracting stems

## Complete Workflow Example

```bash
# Step 1: Prepare dataset (extract real stems from MoisesDB)
python prepare_moisesdb.py

# Step 2: Generate AI-reconstructed stems using Encodec
python generate_ai_stems.py --bandwidths 3

# Step 3: Generate all possible mixes
python generate_mixes.py

# For testing with limited tracks:
python prepare_moisesdb.py
python generate_ai_stems.py --limit 10
python generate_mixes.py --limit 10
```

## Technical Details

### Audio Processing

- **Sample Rate**: 44.1 kHz (throughout the pipeline)
- **Bit Depth**: 16-bit PCM
- **Format**: WAV
- **Channels**: Stereo (2 channels)

### Mixing Algorithm

The script uses the `pad_and_mix` approach from MoisesDB:
1. Find the maximum length among all stems
2. Pad shorter stems with zeros
3. Sum all stems element-wise

This ensures:
- No audio is lost due to trimming
- All mixes are properly time-aligned
- Silent padding is added where stems are shorter

### Naming Convention

Mixes are named according to which stem **indices** are AI-generated:
- `mix_S-empty.wav`: No AI stems (all real)
- `mix_S-0.wav`: Stem 0 is AI-generated
- `mix_S-1-3.wav`: Stems 1 and 3 are AI-generated
- `mix_S-0-1-2-3.wav`: All stems are AI-generated

Indices are:
- 0-based (first stem = 0)
- Sorted in ascending order
- Hyphen-separated

### Dataset Statistics

For a track with **n** stems:
- Total mixes generated: **2^n**
- Mixes per Uk folder: **C(n, k)** where C is the binomial coefficient

Example for 4 stems:
- U0: 1 mix (all real)
- U1: 4 mixes (one fake each)
- U2: 6 mixes (two fake combinations)
- U3: 4 mixes (three fake combinations)
- U4: 1 mix (all fake)
- **Total: 16 mixes**

## Troubleshooting

**"No real stems found"**
- Make sure `prepare_moisesdb.py` ran successfully
- Check that `{track_id}/stems/real/` contains .wav files

**"No AI-generated stems found"**
- Make sure `generate_ai_stems.py` ran successfully
- Verify the codec name matches (e.g., "encodec_3")
- Check that `{track_id}/stems/ai_generated/{codec}/` exists

**"Mismatch in stem counts"**
- Some stems may have failed during AI generation
- Check the logs from `generate_ai_stems.py` for errors
- Re-run AI generation for affected tracks

**Memory issues**
- Process in smaller batches using `--limit`
- Encodec requires substantial memory for longer tracks
- Consider using CPU instead of GPU for Encodec (`DEVICE="cpu"` in script)
